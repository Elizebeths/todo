# 日序 · Daylight

参考滴答清单的使用习惯制作的中文待办应用，全应用采用统一的视觉规范，并提供青叶、鸢尾和深夜三种主题。

## 运行

需要 Node.js 18 或更高版本，无需安装依赖。

macOS 用户可以直接双击项目中的 `启动日序.command`，服务就绪后会自动打开浏览器。保持终端窗口打开，按 `Ctrl+C` 停止服务。

```sh
npm run dev
```

打开 http://localhost:5173 。可以通过 `PORT=端口号 npm run dev` 指定端口。

## 工作空间与看板

默认以青叶主题进入四列看板：待规划、待办、进行中、已完成。支持拖动卡片跨列、列内排序，以及用卡片底部下拉框切换状态；手机端可以横向滑动浏览各列。列内任务过多时独立滚动。

看板和清单是工作空间侧边栏中的两个并列入口，启动时默认选中看板，可通过侧边栏直接切换。点击卡片编辑任务详情；点击列标题旁的加号可直接添加到该列。侧边栏保留任务分类、日历、专注、备份导出与恢复。旧任务会自动映射到看板，保留现有数据。

`npm test` 验证状态切换、旧数据兼容和排序逻辑。

## 功能

- 收集箱、今天、逾期任务、最近 7 天、所有任务、已完成
- 新建清单、任务增删改、日期、时间、优先级、标签和子任务
- 搜索、高优先级过滤、侧边栏切换看板与清单、月历
- 25 分钟专注计时、快捷键、JSON 备份导出与恢复
- 本地自动保存和移动端适配

## 1.1 迭代：清单管理与任务查找

- **管理清单**：点击侧栏清单右侧的省略号，修改名称和颜色。删除前会展示任务数量；确认后将该清单的全部任务移至收集箱，包含已完成任务，保留日期、优先级、备注、标签、子任务和看板状态。
- **任务排序**：看板和清单支持手动顺序、截止日期、优先级和任务名称。日期排序中无日期任务排在最后，同一天按时间排列；无优先级排在低优先级之后。排序仅影响显示，不改写手动顺序；本次打开期间各视图共用排序，刷新后恢复手动顺序。看板切回手动顺序后可继续拖动。
- **搜索与筛选**：搜索覆盖任务名、备注、标签、子任务和清单名称，忽略首尾空格和英文大小写，多个关键词以空格分隔并同时匹配。搜索范围为当前视图，可叠加日期或高优先级筛选；页面显示当前条件并支持一键清除。区分“没有匹配的任务”和空清单，中文输入法组词期间不刷新任务视图。
- **键盘操作**：任务行支持 Tab 聚焦和 Enter / 空格打开详情；弹窗具有标题关联和焦点约束，打开期间背景不可交互，中文组词时不会误触全局快捷键。

`npm test` 包含排序边界、原顺序保留、组合关键词搜索、清单修改和删除后的数据完整性及备份往返检查；HTTP 集成测试验证新增模块可加载。

数据保存在当前浏览器的 localStorage；清除浏览器数据会移除任务。首次打开显示可编辑的示例任务。当前版本不包含账号登录、云端同步、多人协作或系统通知。

`npm run check` 检查 JavaScript 语法。

## 从备份恢复

侧边栏底部「从备份恢复」，选择日序导出的 JSON 文件（不超过 5 MB）。应用会校验文件并展示任务、清单数量；点击「替换并恢复」后才会替换当前数据。确认前可先导出当前数据，或取消操作。

恢复保留任务顺序、状态、日期、优先级、标签、子任务和清单，兼容没有看板状态的旧版导出。格式错误或写入存储失败时，不替换当前数据。

## 数据读取与开发检查

启动时会校验本地数据并兼容旧版任务状态。数据损坏或浏览器禁止读取存储时，会提示并暂时显示示例任务；自动保存会暂停，编辑示例任务也不会覆盖原存储。页面会持续提示异常，只有成功确认恢复备份后才重新启用自动保存。临时编辑可通过导出备份保留。

正常使用时若保存失败，页面会显示“修改尚未保存”，并提供“重试保存”按钮。请在刷新或关闭页面前重试，或导出备份保留修改；保存成功后提示会自动消失。

从清单新增的任务会立即记录看板状态，之后编辑日期或子任务不会自动换列。

开发服务器只提供页面及其所需的 CSS、JavaScript 文件，支持 GET / HEAD。从其他工作目录运行 `node /项目绝对路径/server.mjs` 也可正常访问；启动日志显示实际端口。`npm test` 包含临时监听本机回环端口的 HTTP 集成测试，需允许本地端口监听。

## 截止日期与逾期处理

看板工具栏支持「全部任务 / 今天到期 / 逾期任务」筛选，可与搜索叠加使用；清单侧栏提供「逾期任务」入口和未完成数量。只有截止日期早于本地今天、且尚未完成的任务才计入逾期；今天到期不计为逾期，时间字段仅展示，不按小时判断。

看板卡片与清单行始终显示已设置的截止日期，即使任务包含子任务。逾期日期显示「已逾期」标记；详情中可点击「安排到今天」，仅修改日期，保留时间、状态、优先级与子任务，并自动保存。页面跨天或重新回到前台时会更新日期筛选；正在输入时会推迟刷新，避免打断编辑。

`npm test` 包含跨年日期、筛选边界、已完成任务排除及快速改期的数据完整性测试。

## 外观主题

点击看板或清单页右上角「主题」，或通过左侧图标栏「外观主题」切换：

- **青叶**：清爽的绿色，默认主题。
- **鸢尾**：柔和的紫色。
- **深夜**：蓝灰色深色界面。

主题即时应用到看板、清单、日历、任务详情、专注计时和所有弹窗。选择单独保存在此浏览器的 `daylight-theme` 中，刷新后保留，并同步到同源的其他标签页。浏览器禁止保存时仍可临时切换，界面会提示；主题偏好不包含在任务备份内。

所有视图共用 `style.css` 顶部的语义化颜色变量，以及统一的字体、圆角、表单、按钮和键盘焦点样式。主题在首屏绘制前读取，无需联网下载字体。

## 专注计时

番茄专注按实际经过时间计算剩余时长。浏览器后台限速或设备休眠后，回到页面会立即校准；到时停在 `00:00` 并提示一次，点击「开始专注」开启新一轮。暂停期间不计时，继续时保留剩余时长；「重新开始」恢复为暂停的 25 分钟。关闭弹窗不会暂停，刷新或关闭页面会重置计时。提醒在页面恢复运行时显示，不提供系统通知。

`npm test` 覆盖后台长时间无回调、暂停与继续的毫秒精度、重复启动、完成提醒只触发一次及重置；HTTP 集成测试同时检查计时模块可正常加载。
