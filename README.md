# 日序 · Daylight

中文、本地优先的个人待办工具。当前工作区为 1.7.0 迭代候选版，覆盖 `ITERATION_PLAN.md` 的 M0–M6 实现范围；发布验收状态见 `ITERATION_RESULTS.md`。运行时无第三方依赖，无默认联网遥测。

## 启动

Node.js 18+，双击 macOS 的 `启动日序.command`，或运行：

```sh
npm run dev
```

固定推荐地址：<http://localhost:5173>。本地服务仅监听回环地址。端口占用时先打开已有地址或停止旧服务。`PORT=其他端口 npm run dev` 可以改端口，但 **localhost、127.0.0.1、不同端口及不同浏览器分别保存数据**。换来源前先导出，再到新来源恢复。开发测试需要 Node.js 22+ 和安装开发依赖。

## 使用

首次打开选择「空白开始」或「体验示例」。已有数据不会重新注入示例。侧栏提供看板、清单、收集箱、今天、逾期、最近 7 天、月历和周计划，记住最近视图、排序及完成区域展开状态。

- 看板有待规划、待办、进行中、已完成四列。拖动调整状态和手动顺序，也可使用下拉框。手机横向滑动各列。
- 快速输入创建任务；「新建并安排日期、清单与优先级」提供完整选项。月历点击日期数字可创建当天任务，密集日期可展开，支持返回今天与切换周计划。
- 详情支持名称、备注、日期、时间、清单、优先级、标签；名称和备注输入即时保留，中文组词结束后保存，切换任务、按 Esc 和切视图无需额外点保存。空白名称会保留原名。未保存内容在浏览器允许时触发离开提示。
- 子任务可编辑、上下移动、独立勾选，父任务完成不会自动改写本次子任务。
- 搜索覆盖名称、备注、标签、子任务和清单名，多个关键词同时匹配；明确选择当前视图或全局范围，可叠加标签、清单、日期及高优先级。最多保存 20 个常用筛选。
- 批量整理只选择当前可见结果，支持状态、清单、日期与优先级变更。即时撤销保留最近一批；「规划与数据工具 → 回收站」提供跨刷新恢复。
- 三主题：青叶、鸢尾、深夜。`⌘/Ctrl+K` 搜索、`N` 新建、`Esc` 关闭详情或弹窗，任务行可用 Enter/空格打开。

## 保存、冲突与备份

业务数据保存于 `daylight-v1`，数据格式为 `schemaVersion: 2`，包含任务、清单、回收站、重复规则、完成事件、专注会话及当前计时。导出附带应用版本及时间。主题和界面偏好使用独立键，不包含在任务备份中。

所有应用写入和导入都通过同源 Web Locks 串行化，并比对写前版本及来源。无本地修改时同步其他页面；有草稿、待写入、失败或打开弹窗时保留本页版本并提示冲突。可导出两份数据，明确选择存储版本或本页版本；不做自动合并。不支持 Web Locks 的浏览器进入只读保护，允许导出临时编辑，禁止无锁写回。升级时请关闭仍运行旧版代码的标签页，旧应用不会遵守新写入协议。

保存失败不会清除内存修改，底部提示始终可访问。解决存储权限、配额问题后重试，或先导出文件。**清除浏览器数据会同时删除任务和本地恢复点**，请定期保存独立 JSON 文件。

「从备份恢复」接受无版本旧备份、格式 1 和格式 2，最大 5 MB，校验并预览后再替换。未来不支持版本禁止降级写回；损坏数据不会被示例覆盖，可在工具中导出原始存储。导入失败不替换活动数据。

旧版迁移、导入及选择本页覆盖冲突前保存恢复点，最多 5 份，总字符串约 1,000,000 字符（约 2 MB UTF-16，不含浏览器开销）。无法建立恢复点时中止写入并提示导出。恢复点可导出，再通过备份预览恢复。

回收站保留 30 天，最多 1,000 项；超期记录在后续保存时清理。恢复原位置、状态和元数据，原清单已删除时进入收集箱；同 ID 已存在时拒绝覆盖并保留回收站副本。彻底删除需确认。

## 重复与提醒

为任务设置日期后，在详情「重复规则」配置每天、每周指定星期或每月指定日期，可选择按计划日期/完成日期计算、截止日期、剩余次数（含本次，0 为不限）和暂停续生。

- 完成本次后生成下一项，按计划计算的迟完成逐次补做；按完成日计算则从实际完成日继续。
- 每月固定日期遇短月取月末，原月日锚点保留，例如 1 月 31 日 → 2 月末 → 3 月 31 日。
- 日期使用日历值，不因设备时区变化平移。实例使用规则 ID 和实例日期识别，刷新、重新完成、删除/撤销、恢复备份不会重复生成同一后继实例。
- 规则修改影响本次及由它生成的后续任务，已生成的其他任务不联动修改。停用/删除当前实例不会继续生成。
- 每 30 秒在页面前台检查当天到时任务，页面内聚合提示。本次打开期间每项每日最多一次；重新打开页面可能再次提示。主动授权后可在支持的浏览器发送专注结束通知。

关闭页面后的可靠提醒、跨设备同步和账号不在当前承诺范围。

## 专注与复盘

可从选中任务启动专注，或开启自由专注。支持 1–180 分钟、暂停/继续、提前结束、取消及手动休息。当前会话跟随任务数据持久化，刷新和休眠后按截止时间恢复；同一会话 ID 最多入账一次。系统时间调整会影响剩余时间，回拨最多恢复到本次未用时长。

「规划与数据工具 → 专注与复盘」展示今天/本周完成事件、有效专注时长、最近 7 天完成时逾期次数及最近会话。自然日按设备本地日期，周一为周起点；重新完成会新增完成事件，不用旧任务快照推算缺失历史。提前结束计实际专注时长，取消和休息不计入有效专注。最多保留 10,000 条完成事件和 5,000 条会话，可确认清理或导出完整备份；任务删除后会话仍保留当时名称。

## 离线与更新

首次在线完整加载后，Service Worker 缓存整套发行资源；应用清单提供独立窗口入口。新资源等待所有旧页面关闭再激活，避免正在编辑时切换资源版本。新缓存完整建立前保留旧缓存；资源缓存清理只触及 `daylight-*` Cache Storage，不删除 localStorage。

诊断工具显示来源、版本、存储估算、写入锁和缓存状态，可主动检查更新。离线重载已纳入浏览器测试；浏览器重启、操作系统重启或缓存被回收后的可用性依浏览器而异，不能把 localhost 缓存当作可靠安装或备份。维护缓存资源清单和 `sw.js` 的发行缓存键必须与版本一同更新。

## 开发与验证

```sh
npm ci
npx playwright install chromium firefox webkit
npm run check
npm test
npm run test:browser
npm run benchmark
```

Playwright 为开发依赖，运行应用无需安装它。支持使用已安装 Chrome：`DAYLIGHT_CHROME=1 npx playwright test --project=chromium`。测试使用独立浏览器上下文，不接触日常浏览器数据。失败截图和轨迹在 `test-results/`，HTML 报告在 `playwright-report/`，均不纳入 Git。GitHub Actions 按语法 → 模型/HTTP → 浏览器执行，配置已落库，远端实际运行需推送后验证。

`BENCHMARK.json` 记录本机 100/1,000/5,000 条数据的 p50/p95。搜索/切视图/月历度量同步 JS 筛选及重建 DOM，不含绘制、输入防抖；保存度量实际仓储校验、锁和 localStorage 写入。它不能代表其他设备或用户体验全链路延迟。

模块包括 `storage.js`（并发与快照）、`backup.js`（兼容校验）、`task-commands.js`（编辑命令）、`recurrence.js`（日历规则与完成事件）、`focus-session.js`（持久专注）、四个 `*-view.js`（任务展示）、`workspace-tools.js`（规划及恢复工具）。原模型模块和兼容测试继续保留。

## macOS 桌面应用

独立封装源码与构建说明见 [macos-app/README.md](macos-app/README.md)。桌面版复用本仓库全部网页业务代码，提供 Apple Silicon 和 Intel 的 `Daylight.app`；在 [Build macOS app](https://github.com/Elizebeths/todo/actions/workflows/macos-app.yml) 成功运行的 Artifacts 下载。桌面数据独立保存，网页迁移需先导出备份再恢复。应用仅 ad-hoc 签名，未进行 Apple 公证。
